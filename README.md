# daily-ai-project-2026-10-12-trace-llm-observability
A lightweight SaaS‑style service that records every LLM call, stores prompts/responses with vector embeddings, streams OpenTelemetry traces, and automatically grades output with an LLM‑as‑judge. The data is visualized via a minimal React dashboard for latency, token usage and hallucination risk. Build-it-yourself AI/ML project.
